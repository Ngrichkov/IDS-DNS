# Servidor de Chat
Implementação de um servidor de chat, onde clientes podem se conectar e trocar mensagens com o servidor e com outros clientes simultaneamente.

# Modo de uso:
1. Compilar e rodar o código do servidor;
2. Compilar e rodar o código do cliente com o endereço IP do servidor como argumento (Ex: ./cliente 127.0.0.1);
3. A partir desse momento, o cliente e o servidor podem trocar mensagens simultaneamente;
4. A conversa é encerrada quando um dos lados encerra o programa ou envia "Adeus";
